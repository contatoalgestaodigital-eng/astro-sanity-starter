# AL Gestão Digital — landing page

Projeto final em Astro preparado para GitHub e Netlify.

## Abrir no computador

1. Instale o Node.js 22 ou mais recente.
2. Abra esta pasta no VS Code.
3. No terminal, execute `npm install`.
4. Depois execute `npm run dev`.
5. Abra o endereço informado pelo terminal.

## Publicação

A Netlify deve usar `npm run build` como comando de construção e `dist` como pasta de publicação. Essas configurações já estão registradas no arquivo `netlify.toml`.
